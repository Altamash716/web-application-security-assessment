# Web Application Security Assessment

## Project Overview
A hands-on cybersecurity training project involving the assessment of a simulated web application in a controlled VMware lab environment using Kali Linux.

## Objectives
- Perform network reconnaissance and service discovery.
- Examine FTP access and potential file exposure.
- Inspect web application source code.
- Enumerate web directories and endpoints.
- Analyze HTTP traffic using Burp Suite.
- Document security observations and remediation recommendations.

## Tools Used
- Kali Linux
- Nmap
- FTP
- Gobuster
- SecLists
- Firefox Developer Tools
- Burp Suite
- VMware Workstation

## Key Learnings
- Cybersecurity fundamentals
- Network and web application security
- Security assessment methodology
- Identification of potential security weaknesses
- Security documentation and remediation

## Project Report
The original PDF report is available in this repository and contains the assessment methodology, observations, findings, limitations, and recommendations.

## Disclaimer
This project was conducted in a simulated lab environment for educational purposes. Findings are limited to the observations documented in the report.
